# 0.6.0-test9-vanilla51

The native edition could reject Minecraft 1.26.51.01 after removing LeviLamina:
neither the Mods button nor F10 was available, and the log stopped at
`INACTIVE: disk-identity`.

The previously reviewed 51 fixture already included an extra `.nimp` section
and a `PreLoader.dll` import. This release adds exact whole-file identities for
the independently checked image without that import, and its LeviLauncher form.
All eight original section headers and contents, the original entrypoint and
every ModMenu entry guard match the reviewed 51 fixture byte-for-byte. The 51
address table, layout, hooks and loaded-header policy are unchanged. GUI and
console forms have separate pinned hashes; arbitrary header edits remain refused.

This is a native-edition compatibility correction. No LeviLamina API dependency
is added, and the separate LeviLamina edition is not changed. The other three
version profiles and resource-pack entry API remain available. Regression also
identified a 26.60 LeviLauncher console form differing from the pinned GUI image
at exactly one byte (`OptionalHeader.Subsystem`). Its complete hash is now pinned
separately; no 26.60 code, addresses or layout changed.

## Verification

The new regression fails against test8 for the two newly encountered images.
It covers exact GUI/console identities, retained PreLoader identity, original
code/data/overlay mutations and loaded-header mismatches. Debug/Release and
private image/menu checks must pass before packaging. Gameplay acceptance of
this newly built DLL remains pending until manual testing.
