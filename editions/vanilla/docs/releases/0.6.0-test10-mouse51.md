Native-edition prerelease, paired with MouseTweaksBedrock
`0.3.3-test1-vanilla51`. Includes the intervening test6-test9 work.
The inspected 26.51 session reached Ready in both plugins and opened Mods with
zero reported ModMenu faults. Full gesture and second-launch acceptance is pending.

The 26.51 game without LeviLamina was already admitted by test9. MouseTweaks
needed its own exact-image update first; ModMenu must then independently
recognize that new DLL before sharing the pointer/down/up hooks.

This candidate retains the old accepted MouseTweaks image and adds only the
following exact size/hash pair. Formal `MTB_GetStatus()==3`, export module
ownership, pinned module lifetime and actual shared jump ownership remain
mandatory. Unknown hashes, modified sizes and inactive dependencies are refused.
No address, layout, gesture or hook set changes are made.

## Verification and testing

The new real-DLL regression first fails at the old admission gate. After the
update, the exact new and old DLLs reach the formal Ready gate, while copies
with appended data or a changed timestamp are refused by image admission.
The unsupported test host deliberately never makes MouseTweaks Ready.
Independent MinHook fixtures check actual jump ownership, original caller,
arguments, return value, exactly-once forwarding and restoration of the
underlying owner. These offline checks do not replace gameplay testing.

Close Minecraft and back up both plugin folders. Apply the paired update
archives to the selected instance, keeping existing settings and logs.
MouseTweaks must be enabled in the native loader; if its manifest is currently
`manifest.json.close`, restore one active `manifest.json` for this test.
Do not leave duplicate loadable manifests or copies of either DLL.

On 26.51 without LeviLamina, check both Ready logs, main/pause Mods buttons,
the configured shortcut, Shift-left drag across mixed items, left collection,
right placement, wheel transfer and input after closing the container/menu.
Repeat a second launch, including console disabled when applicable.
The newly rebuilt 26.45/26.52 MouseTweaks DLL also needs manual regression.
