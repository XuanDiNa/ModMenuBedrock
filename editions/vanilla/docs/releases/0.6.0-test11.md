# ModMenu 0.6.0-test11

Fixes 1.26.60.05 startup refusal (`INACTIVE: disk-identity`) when LeviLauncher
captures a console-enabled original before rebuilding its import section.
The old profile covered enabling the console after that rebuild, missing the
other checksum order. All eight original section headers and contents, plus the
original entrypoint, match the independently reviewed 26.60 image exactly.

Only three reviewed full-file hashes are added: the console original and the
GUI/console launcher forms with checksum `0x134D3CBB`. The two launcher forms
with `0x134D3CBA` and the earlier exact PreLoader form remain admitted.
No runtime header normalization, address changes or guard relaxation is used.
Full image, code, loaded-header, entry, hook-owner, Ready, foreground and scene
checks remain required. Arbitrary checksum/subsystem, code, data, import and
launcher mutations are refused by regression tests using private copy-on-write
pages. No game file is changed.

This release retains test6–test10 features and old-version profiles; see
[cumulative release notes](../../../../docs/releases/2026-11-15-vanilla-test11.md).
Settings v1–v5, Workspace V1 and resource-pack entry v1 remain compatible.
Providers pinning the exact ModMenu DLL must explicitly admit this new binary.
The independent LL edition and other plugins are unchanged.

Debug/Release offline verification and exact private-image checks are recorded
in the release provenance. Manual gameplay acceptance for test11 is pending.
