# ModMenuBedrock 0.5.0-test1

## English

Native client-side plugin browser and settings menu for LeviLauncher.
Windows x64 · Minecraft 1.26.45.01 / 1.26.51.01 / 1.26.52.03.

- Native main/pause Mods buttons, F10/custom key and loaded-only plugin discovery.
- Shared Configure controls, key unbinding and game-language-following labels.
- New optional schema-v2 sliders with signed integers, fixed-precision decimals,
  direct input, keyboard adjustment and draft-only Apply/Cancel.
- Existing v1 descriptions, built-in adapters and native compatibility checks retained.
- MIT-licensed source and standalone build/test instructions.

The maintainer has tested basic use of the retained DLL on all three builds.
This remains a prerelease: long sessions, OreUI and arbitrary menu packs have not
been exhaustively verified. No LeviLamina API, resource pack or server plugin is
required. Sliders need explicit author integration; other plugins are not updated.

Close Minecraft before installation. Extract the ZIP's `ModMenuBedrock` folder
into the selected version's `mods`, preserving existing config, logs and launcher
enabled state. Back up your old installation first. Do not install the examples
as plugins. Source ZIPs generated by GitHub are not the ready-to-use DLL package.

The release retains the tested DLL (836608 bytes), SHA-256:

## 繁體中文

LeviLauncher 原生客戶端插件清單及設定選單，支援上述三個精確 Windows x64 版本。

- 主選單／暫停選單 Mods、F10／自訂鍵及只列已載入插件。
- 共用設定介面、按鍵解除綁定及跟隨遊戲語言。
- 新增選用 v2 滑動條，支援正負整數／固定精度小數、數字輸入、鍵盤與 Apply／Cancel。
- 保留 v1、既有適配器及原生相容檢查，原始碼採 MIT 授權。

維護者已在三個版本人工測試此份 DLL，基本使用正常；仍屬預發佈版，長時間使用、
OreUI 與任意選單資源包尚未全面驗證。不需要 LeviLamina API、資源包或服務端插件。
滑動條需作者明確接入，本次不更新其他插件。

安裝前完全關閉遊戲並備份，將 ZIP 內的 `ModMenuBedrock` 放入對應 `mods`，保留
設定、日誌及啟用狀態；不要安裝範例，也不要把 GitHub 自動產生的原始碼 ZIP 當作
DLL 套件。發佈保留上方雜湊的實測 DLL，只更新授權與公開文件。
