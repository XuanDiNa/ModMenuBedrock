# 0.6.0-test5-leftalt

## English

ModMenu-only prerelease for Windows x64 / LeviLauncher, supporting Minecraft
**1.26.45.01 / 1.26.51.01 / 1.26.52.03**.

- Add opt-in Ctrl / Shift / Left Alt combinations and Esc-to-Unbound capture.
- Preserve settings v1–v4 and add the opt-in v5 binding contract.
- Add shared text controls and asynchronous plugin workspaces.
- Fix Workspace mapped clicks and retain navigation across temporary focus loss,
  while clearing transient input and keeping scene/provider protection.
- Revalidate the independent native profiles for all three game builds.

The maintainer reported the latest 26.45 / 26.51 compatibility tests passed.
Debug and Release each passed 22 suites, including 94 exact-image checks and
431 binding checks; schema/parser agreement covered 3,525 cases. Private vanilla
menu fixtures were unavailable and skipped. Custom menus, OreUI and arbitrary
Workspace providers are not exhaustively tested.

The DLL is unchanged from the tested package: **974,336 bytes**,
SHA-256 `FD314F0EFC6397D1229B2F18A62DCEC5B8C404829E3A13A28B14F137C4BF2F74`.
Public packaging updates documentation and includes dependency licenses.
No other plugin DLL, user settings, account data, game file or IDA data is included.

Close Minecraft, back up ModMenu outside the active mods folder, then merge the
update while preserving config.json, logs and launcher enabled/disabled state.
Plugins interpret their own bindings; updating ModMenu alone does not add chord
support to older plugins. Providers that pin a DLL hash need a matching version.
See [installation](package-installation.md) and [testing](../../TESTING.md).

## 繁體中文

只包含 ModMenu 的 Windows x64／LeviLauncher 預發佈版，支援 Minecraft
**1.26.45.01／1.26.51.01／1.26.52.03**。

- 新增選用的 Ctrl／Shift／左 Alt 組合鍵，綁定時 Esc 設為無綁定。
- 保留 v1–v4 設定相容性，新增明確接入的 v5 綁鍵規格。
- 新增共用文字控件與非同步插件工作頁。
- 修正 Workspace mapped 點擊及暫時失焦保留頁面，同時清除暫態輸入，
  保留場景及提供者保護。
- 重新驗證三個遊戲版本各自的原生配置。

維護者回報最新 26.45／26.51 相容測試通過。Debug／Release 每模式各通過 22 組測試，
包含 94 項精確映像及 431 項綁鍵檢查；Schema／解析器對照有 3,525 個案例。
私有原版選單資料無法取得，已略過；自訂選單、OreUI 及任意工作頁提供者尚未全面驗證。

DLL 與人工測試包完全相同：**974,336 bytes**，
SHA-256 `FD314F0EFC6397D1229B2F18A62DCEC5B8C404829E3A13A28B14F137C4BF2F74`。
公開套件只更新說明並補齊依賴授權，不含其他插件 DLL、使用者設定、帳號、遊戲檔或 IDA 資料。

退出遊戲，將 ModMenu 備份到 mods 以外再合併更新，保留 config.json、日誌及啟用／停用狀態。
各插件自行解析快捷鍵，只更新 ModMenu 不會讓舊插件自動支援組合鍵；限定 DLL 雜湊的提供者
需要相容版本。詳見[安裝](package-installation.md)及[測試](../../TESTING.md)。
