# 0.6.0-test5-leftalt

## English

**Prerelease. New DLL gameplay acceptance is pending.** Offline checks do not
replace manual testing. Existing releases and frozen DLLs are retained.

### Changes

- Add opt-in settings v5 keyboard bindings with Ctrl, Shift and Left Alt,
  including all seven nonempty modifier combinations.
- Keep existing v1–v4 settings contracts and legacy single-key values readable.
- Capture complete combinations, standalone modifiers on release, and Esc to
  Unbound. Apply saves; Cancel does not.
- Require an exact modifier mask and a fresh main-key press. Held keys, late
  modifiers and focus/config changes do not manufacture actions.
- Include the 0.6 workspace/text-setting API, mapped workspace clicks and
  navigation retention across temporary focus loss.

### Downloads

  existing exact builds 1.26.45.01, 1.26.51.01 and 1.26.52.03.
- `ModMenu-matched-bindings-26.52-win-x64.zip`: flat `mods` update for an

The native DLLs are byte-identical to the frozen matching test candidates;
public packaging adds full dependency licenses and public installation notes.
No user settings, account data, Java program, player assets, runtime, game files

not the source/runtime of the seven independent companion plugins.

### Updating and testing

Exit Minecraft. Back up affected folders outside `mods`, then merge the update.
Replace DLL, manifest and settings description together; keep settings and all
unrelated files. Do not delete whole plugin folders or load duplicate DLLs.
Preserve the launcher's enabled/disabled manifest state.

Muonium is an **update-only native DLL for an existing 0.7.0-test1 installation**;
retain its Java/runtime/player files. This release does not distribute or clear
the rights to those separate assets. ContainerPreview remains a hold action;
the existing sneak/Shift guard for new background opens is unchanged.

Run the bundle's `CHECK-INSTALL.ps1 -ModsPath <your-mods-directory>` with
PowerShell. It is read-only and checks all eight complete sets; an intentionally
omitted or disabled plugin may be reported as missing. Then manually check
Ctrl+K, Shift+K and LeftAlt+K capture, Apply/reopen, actual actions, and Esc
unbinding, one plugin at a time. See [full test steps](../keybindings-testing.md).
For rollback, restore the backed-up DLL, manifest, description and settings together.

**BedrockToolNative 0.2.0-test5 only admits the older ModMenu test3 hash. It will
reject this release.** Its companion admission was not changed. Do not bypass it.
Windows-reserved shortcuts, Right Alt/AltGr as a LeftAlt substitute and firmware
Fn are not guaranteed. This update adds no game-version support.

### Verification scope

The release gate runs 22 public suites in each of Debug and Release, exact-image
checks where locally available, schema/parser agreement over 3,525 cases,
431 focused binding checks and 898 bundle checks across fourteen activation
fields. Checksums identify the downloadable files. Private vanilla-menu fixtures
are not distributed; their absence is reported as a skip, not a pass.
The old 0.5.0 gameplay acceptance does not cover these new DLL hashes.

## 繁體中文

**預發佈版，新 DLL 的遊戲內驗收仍待完成。** 離線檢查不等於人工遊戲測試；
舊 Release 及凍結 DLL 均保留。

### 更新內容

- 新增選用的設定 v5 組合鍵，支援 Ctrl／Shift／左 Alt 的七種非空修飾組合。
- 舊 v1–v4 規格及原有單鍵值保持相容，不自動改寫既有設定。
- 完整組合鍵擷取、放開確認單獨修飾鍵、Esc 設為無綁定；Apply 儲存、Cancel 捨棄。
- 精確比對修飾鍵並要求新的主鍵按下；按住、後補修飾鍵、失焦或設定變更不會誤觸發。
- 包含 0.6 文字設定及工作頁 API、工作頁 mapped 點擊與暫時失焦時保留導覽。

### 下載及安裝

ModMenu 單獨包維持三個精確版本支援；七插件配套包只適用 **1.26.52.03**。
各插件版本見上表。先退出遊戲，將備份放在 mods 以外，再合併更新目錄；
DLL、manifest 與描述檔一起替換，保留原有設定、啟用／停用狀態及其他檔案。
不要刪除整個插件目錄，也不要同時載入新舊 DLL。

八個 DLL 與凍結測試包完全相同，公開包只補齊依賴授權及公開安裝說明。
不包含使用者設定、帳號、Java 程式、播放器資源、runtime、遊戲檔或 IDA 資料。
本倉庫及原始碼 ZIP 是 ModMenu 原始碼，不包含七個獨立插件的原始碼或執行環境。

Muonium 是既有 **0.7.0-test1** 的原生 DLL 更新，不是完整播放器；保留原有
Java、runtime 及播放器檔案，本次不發佈或宣告那些獨立資源的再散布權利。
容器預覽仍需按住按鍵，原有潛行／Shift 背景開箱保護不變。

可用 PowerShell 執行配套包的 `CHECK-INSTALL.ps1 -ModsPath <你的-mods-目錄>`。
工具唯讀核對八組檔案；自行省略或停用的插件可能顯示缺少。接著逐一測試
Ctrl＋K、Shift＋K、左 Alt＋K 的擷取、套用、重開保留、實際功能及 Esc 解除綁定。
完整操作見[測試步驟](../keybindings-testing.md)。回退時一併還原 DLL、manifest、
描述檔及設定備份。

**BedrockToolNative 0.2.0-test5 綁定舊 ModMenu test3 雜湊，會拒絕本版。**
本次未修改 companion 檢查，請勿繞過。Windows 保留組合、以右 Alt／AltGr 代替左 Alt、
韌體 Fn 不保證可用，也未新增遊戲版本支援。
