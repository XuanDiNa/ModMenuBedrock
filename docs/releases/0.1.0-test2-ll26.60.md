# ModMenuBedrockLL 0.1.0-test2-ll26.60

Adds exact-image support for the independently reproduced **PreLoader first,
LeviLauncher second** patch order. test1 covered the reverse installation order
and refused the player's valid alternate image at `disk-identity`.

The player report identifies the correct released test1 ModMenu DLL and official
LeviLamina 26.60.7 on disk. No running process was recorded, so this report does
not assert loaded-memory identity or hook coexistence. The matching full-file
reproduction below establishes the alternate file, rather than admitting it
based only on reported `.text` equality.

| Variant | Whole-file SHA-256 |
| --- | --- |
| GUI | `FCBCCAEC4E0EE3AB203146BDF45E41878AED7B42237E6DE2C5053F0730C6E10B` |
| Console, observed by player | `B554A2DA8B2271A4A164AE544A4A447F3A630B5FC2261AFEFE47C7C206826A53` |

Both files contain 323,855,872 bytes and PE identity
`8664 / 6AD79EE4 / 13847000 / 134DC051`. The GUI form's stored PE checksum is
correct; the console form retains that checksum when only Subsystem changes,
matching LeviLauncher's `SetSubsystem` behavior. Runtime validation does not
normalize either field and accepts only the two reviewed complete hashes.

Preparation uses an exact original 26.60.05 image and official PeEditor 3.9.3.
The reproduced `.nimp` SHA is
`10791D16407A2C81E04EBC0729152B2023D281D631C0E0841E5C41ABAE7FD6B6`;
the appended `.levildr` SHA is
`658D1BB525A68464E9EC314209A39884758580E7DE25C1F7E9418D62DF7609E9`.
All eight original game section headers/bytes, the original entrypoint, and
all 1,012 imported symbols across 88 original DLL descriptors retain their
targets and IAT RVAs. Official PeEditor relocates DLL-name strings into `.nimp`
and places its PreLoader import first; the launcher appends its one new import.
The complete console reconstruction matches the player report's SHA-256.
Fixtures are private offline data, never bundled or installed.

The fix extends a single extra-image slot to a bounded immutable descriptor
span and adds the exact pair. No address, layout, hook, ownership, foreground,
scene or provider guard changes. Unknown image mutations are still rejected.
The original vanilla project and all installed DLLs/configs remain untouched.

Regression: old source fails nine new positive admission checks; fixed source
passes 57 native checks including code, payload, truncation and loaded-header
mutation rejection. Debug and Release each pass all 28 offline suites, including
20 lifecycle checks. Integration/schema and 94 resource-pack entry checks pass.
The build harness explicitly selects the isolated regression project/file to
avoid accidentally running older test binaries. Reports and package results
are recorded with the frozen release. Gameplay remains for the affected player's
acceptance.
